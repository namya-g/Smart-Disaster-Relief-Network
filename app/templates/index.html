What SDRN does

Three roles, one workflow, and records that stay in one database.

{{ icon('clipboard', 22) }}

Help requests

Citizens describe what they need, choose a category and a self-reported priority, and can mark a location on the map. They can follow the status of their own requests.

{{ icon('shield', 22) }}

Review and assignment

Administrators approve or reject pending requests and assign approved ones to registered volunteers. Every status change is recorded in a history.

{{ icon('users', 22) }}

Volunteer tasks

Volunteers see only the requests assigned to them and move each one through the allowed steps: start work, then mark it resolved.

{{ icon('tent', 22) }}

Shelters

Administrators maintain shelter records with capacity, occupancy and status. Signed-in users can browse them.

{{ icon('box', 22) }}

Relief resources

Supplies are listed with quantity, unit and availability, and are maintained by administrators.

{{ icon('map', 22) }}

Interactive map

Leaflet and OpenStreetMap show shelters, resources and only the requests a user is permitted to see.

How it works

A request moves through a fixed set of steps, and the server rejects any step that is not allowed.

  1. Submit

    A citizen sends a request with a description and optional location.

  2. Review

    An administrator approves or rejects the pending request.

  3. Assign

    An approved request is assigned to a registered volunteer.

  4. Work

    The volunteer starts the task and marks it resolved when done.

  5. Track

    The citizen follows progress on the request page and its status history.

About this project

SDRN is a B.Tech CSE/CSIT Semester 3 Mini Project Lab project built with Flask, SQLite and vanilla JavaScript. It demonstrates role-based access control, a validated request workflow, and map-based display of stored data.

Any sample shelters and resources in a demonstration are fictional. Map markers show data stored in this application, not verified emergency information, and the map needs an internet connection to load its tiles.
